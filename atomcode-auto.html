atomcode-auto

atomcode CodingPlan 多账户额度查询与切换工具

这是什么

atomcode 的 CodingPlan 免费额度按 5 小时滚动窗口 计量。如果你有多个 AtomGit 账号， 这个工具可以：

  • 📊 一条命令查看所有账户的当前窗口用量、重置时间
  • 🔄 一键切换到额度充足的账户（复制凭证快照到 auth.toml）
  • 🚀 启动 atomcode 前自动展示用量，参数原样透传

安装

macOS / Linux

curl -fsSL https://wsh66660.github.io/atomcode-auto/install.sh | bash

Windows（PowerShell）

irm https://wsh66660.github.io/atomcode-auto/install.ps1 | iex

前置要求：本机需已安装 atomcode。 安装脚本会自动下载主脚本到 ~/bin/、配置 PATH 并做安装检查。

使用

① 添加账户（每个账户只需一次，自动完成登出 → OAuth 登录 → 存快照）：

atomcode-auto login A    # 第一个账号
atomcode-auto login B    # 下一个账号

② 查看各账户用量：

$ atomcode-auto status
当前: w771920097
  w771920097  52%   重置 10:45
  B           100%  重置 12:30

③ 切换账户：

atomcode-auto use B      # 切到 B，下次启动 atomcode 生效
atomcode-auto use        # 忘记名字时，列出所有已存账户

④ 日常启动（先展示用量，再启动 atomcode，参数透传）：

atomcode-auto            # 等价于查看用量 + 启动 atomcode
atomcode-auto -c         # 继续上次会话

工作原理

  • 每个账户登录后，凭证快照存于 ~/.atomcode/accounts/<名字>.toml
  • use 即把对应快照复制为 ~/.atomcode/auth.toml，atomcode 启动时读取的就是它
  • 用量数据来自 GitCode 接口 codingplan_token_usage（以当前 auth.toml 的 access_token 查询）

注意事项

  • ~/.atomcode/accounts/ 下是账号凭证，不要外泄该目录或将其提交到仓库
  • token 过期后重新 atomcode-auto login <名字> 刷新即可
  • 切换仅对新启动的 atomcode 会话生效，运行中的会话需退出重进
  • 仅适用于 AtomGit CodingPlan（OAuth 登录）方式，不适用于 API Key 方式
